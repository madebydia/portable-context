# Standing instruction template

Add the following to your host's persistent instructions only after adapting the paths and scope. Keep the filled-in version private. This example opts into automatic capture across that host's conversations.

```text
Use <absolute path or accessible reference to portable-context/SKILL.md>
by default for work that depends on my context or produces durable decisions,
corrections, useful findings, artifacts, or stopping points. Read it before
that work unless already loaded, and refresh relevant context when needed.

My context store, routing rules, and exclusions are described in
<absolute path or accessible reference to my private context map>.

I authorize automatic durable-context capture across conversations in this
host, within that map's scope. Save meaningful supported context without
per-topic approval, using existing authoritative notes or focused new notes
under the established organization. Keep my decisions distinct from assistant
proposals. Honor no-save requests and narrower task instructions. Keep
synthetic fixtures isolated. If the store is unavailable, identify what is
unsaved. This grants no new data access, external-action permissions,
broad historical backfills, or schedules.
```
